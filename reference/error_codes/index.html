Error Codes Reference

Whenever a command fails, the Mini IoT Gateway (MGW-IoT-002) returns Result: error along with an Error-Code header formatted in hexadecimal, followed by a descriptive error message in the response body.

Example Wire Error Frame​

Transfer-Mode: normal
Result-Len: 42
Data-Len: 42
Data-Position: 0-41
Duration: 12 ms
CRC32: a1b2c3d4
Result: error
Error-Code: 9005

Invalid Access Token. Login first required.

1. Security & Authentication Errors​

Wire Code (Hex)MeaningRecommended Fix
9004Invalid PasswordVerify the administrator password submitted during cmd login.
9005Invalid Access Token / Unauthenticated BusOver UART/SPI: Execute cmd login -u admin -p admin once on boot.
Over Web/BLE: Attach a valid --token "<44_char_token>" flag.
b02Username Not FoundCheck the username spelling (default is "admin").
b03Wrong PasswordVerify your custom admin password. If forgotten, hold Pin 15 (IO28) LOW for 10 seconds to perform a Factory Reset.

2. Command Parsing & Execution Errors​

Wire Code (Hex)MeaningRecommended Fix
9001Empty / Null CommandEnsure your command string is non-empty and properly terminated with \r\n.
9002Invalid Command LengthEnsure the command string does not exceed the maximum line limit (1024 characters).
9003Invalid Command SyntaxCommands must start with cmd and balance all double quotes ("). Escape inner quotes with \".
9101Command Not RecognizedCheck the spelling of your command against the Command Reference Manual.

3. General & System Errors​

Wire Code (Hex)MeaningRecommended Fix
101Out of MemoryRequested allocation or plugin size exceeds active limits. Retry or reduce payload size.
102Invalid ArgumentOne or more command parameters are missing, out of range, or formatted incorrectly.
103Invalid StateThe requested subsystem is not in the required state (e.g., invoking SignalR before connecting).
104Invalid SizeParameter length or file buffer size does not meet requirements (e.g., SoftAP password under 8 chars).
105Resource Not FoundTarget file, key, or transaction ID does not exist.
106Not SupportedThe requested operation is not supported in the current mode.
107Operation Timed OutNetwork connection, Wi-Fi DHCP lease, or flow-control ACK timed out. Verify physical links.
109Invalid CRC / ChecksumSerial or stream data integrity check failed. Inspect wiring and ground connections, then retry.
a400Buffer FullTransmit or receive ring buffer saturated. Reduce polling rate or enable --flow ack.
a401Queue FullCommand worker queue is busy. Wait for the active command to finish before submitting another.
a700Hardware FailureUnderlying physical peripheral error. Verify power supply stability and pin wiring.
ffffffffGeneric FailureGeneral execution failure. Check the response body text for specific diagnostic details.

4. Network & HTTP Errors​

Wire Code (Hex)MeaningRecommended Fix
9201Missing URLProvide a valid target URL via --url "...".
9202Invalid URL FormatEnsure the URL includes the scheme (http:// or https://) and contains no unescaped spaces.
9204HTTP Buffer OverflowResponse body exceeds Normal Mode limits. Use Stream Protocol V2 (--stream true).
3000Wi-Fi Link DownGateway is disconnected from the router. Run cmd restore-wifi or cmd set-wifi.

Support​

If you encounter persistent hardware errors that cannot be resolved through Factory Reset, please contact technical support through CONSTH Vietnam.
