Command Reference Manual

The Mini IoT Gateway (MGW-IoT-002) supports two invocation formats across UART, SPI, BLE, WebSockets, and HTTP REST:

  1. CLI Command Strings: Human-readable command-prompt syntax (e.g., cmd set-wifi --ssid "MyRouter" --password "Pass123").
  2. AST Expressions: C-style function calls (e.g., set_wifi("MyRouter", "Pass123")).

(Note: All commands sent over physical UART/SPI must end with \r\n. Commands executed over wireless interfaces when an admin password is set must include --token "<your_44_char_token>" unless marked as Public).

1. Universal Streaming Flags​

Commands that stream data (such as cmd http, cmd http-download, cmd scan-wifi, and cmd fs-read) support these optional execution flags:

FlagTypeDefaultDescription
--streamBooleanSkill DefaultForces Stream Protocol V2 (true) or Normal Mode (false)
--flowString"none"Flow control mode: "none", "ack" (1-byte 0x06 ACK), or "rts"
--ack-timeoutNumberGlobal SettingCustom ACK wait timeout in milliseconds for this command

2. System, Diagnostics & Time​

CommandArgumentsDescription
cmd versionNone(Public) Queries the running gateway firmware version
cmd get-macNone(Public) Queries the 12-character hexadecimal base MAC address
cmd echo-c / --content (String, Req)(Public) Echoes back the input string for serial link verification
cmd restart-m / --mode (String, Opt)(Public) Reboots the gateway ("configure" or "normal")
cmd factory-resetNoneWipes all custom NVS settings and reboots into Configure Mode
cmd set-startup-mode-m / --mode (String, Req)Sets the persistent boot mode ("configure" or "normal")
cmd get-startup-modeNoneQueries the currently saved boot mode
cmd get-timeNoneQueries current date, time, and configured timezone
cmd set-time-t / --time (String, Req)
-z / --zone (String, Opt)		Sets system clock ("dd/MM/yyyy HH:mm:ss") and timezone (e.g. "UTC+7")
cmd enable-logNoneEnables diagnostic log output on the debug console
cmd disable-logNoneSilences diagnostic log output on the debug console
cmd result-lengthNone(Public) Queries byte length of the latest cached transaction result
cmd get-result-f / --from (Number, Req)
-t / --to (Number, Req)
-i / --id (Number, Opt)		(Public) Retrieves a byte slice from a completed transaction

Examples​

cmd echo -c "Hello Gateway"
cmd set-time --time "05/11/2026 20:15:30" --zone "UTC+7"
cmd restart --mode "normal"

3. Security & Authentication​

CommandArgumentsDescription
cmd login-u / --username (String, Req)
-p / --password (String, Req)		(Public) Unlocks UART/SPI session; returns a 44-char Access Token
cmd verify-token-t / --token (String, Req)(Public) Verifies whether a 44-char Access Token is valid
cmd set-password-p / --password (String, Req)
-c / --confirm_password (String, Req)		Sets a custom administrator password
cmd get-passwordNoneQueries the currently configured administrator password
cmd delete-passwordNoneResets the administrator password back to default ("admin")
cmd set-credentials--new_user (String, Req)
--old_pass (String, Req)
--new_pass (String, Req)		Atomically updates both admin username and password

Examples​

cmd login -u "admin" -p "admin"
cmd set-credentials --new_user "operator" --old_pass "admin" --new_pass "SecurePass123!"

4. Hardware Interfaces & Peripherals​

CommandArgumentsDescription
cmd setting-uart-b / --baud_rate (Number, Opt)
-d / --data_bits (Number, Opt)
-p / --parity (String, Opt)
-s / --stop_bits (String, Opt)		Configures UART parameters and persists them (9600–921600, 7/8, "disable"/"even"/"odd", "1"/"2")
cmd get-setting-uartNoneQueries the active physical UART parameters
cmd uart-send-c / --content (String, Req)Transmits raw string bytes directly over UART1
cmd disable-uartNoneDe-initializes UART peripheral drivers
cmd set-fs-bridge-channel-c / --channel (String, Req)Sets the bridge data channel ("UART1" or "SPI1")
cmd get-fs-bridge-channelNoneQueries the active bridge data channel
cmd set-global-ack-timeout-t / --timeout (Number, Req)Sets global 1-byte ACK timeout in ms (100 to 60000)
cmd get-global-ack-timeoutNoneQueries the active global ACK timeout in ms
cmd gpio-config-p / --pin (Number, Req)
-t / --type (String, Req)		Configures GPIO pin mode ("input" or "output")
cmd gpio-set-p / --pin (Number, Req)
-l / --level (Number, Req)		Sets digital output level (0 or 1) on a GPIO pin
cmd gpio-get-p / --pin (Number, Req)Reads digital input level ("0" or "1") from a GPIO pin

Examples​

cmd setting-uart --baud_rate 921600 --data_bits 8 --parity "disable" --stop_bits "1"
cmd set-fs-bridge-channel -c "SPI1"
cmd gpio-config --pin 8 --type "output"
cmd gpio-set --pin 8 --level 1

6. HTTP, WebSockets & SignalR Cloud​

CommandArgumentsDescription
cmd http--url (String, Req)
--method (String, Opt)
--body (String, Opt)
-h / --header (String, Multi)		Sends an HTTP/HTTPS request (GET, POST, HEAD) and streams response
cmd http-download--url (String, Req)
--filename (String, Opt)
-h / --header (String, Multi)		Downloads a remote file to storage
cmd set-http-default-header-h / --header (String, Req)Saves a persistent global HTTP header (e.g., Bearer Token)
cmd delete-all-http-default-headerNoneClears all globally saved HTTP headers
cmd ws-start-u / --url (String, Req)Connects background WebSocket client to a URI
cmd ws-send-c / --content (String, Req)Sends a text payload over the active WebSocket connection
cmd ws-stopNoneTerminates the active WebSocket client connection
cmd signalr-start-u / --url (String, Req)
-t / --token (String, Opt)		(Public) Connects and handshakes with an ASP.NET Core SignalR Hub
cmd signalr-invoke-m / --method (String, Req)
-a / --args (String, Opt)		(Public) Invokes a remote RPC method on the SignalR Hub
cmd signalr-statusNone(Public) Queries SignalR Hub connection status ("OK" or "NG")
cmd signalr-stopNone(Public) Disconnects from the SignalR Hub
cmd start-http-serverNoneStarts the local HTTP REST server
cmd start-web-serverNoneStarts the full Web Dashboard, mDNS, and WebSocket server
cmd send-all-clients-c / --content (String, Req)Broadcasts a raw text frame to all connected WebSocket browsers

Examples​

cmd http --method POST --url "https://api.example.com/data" --header "Content-Type: application/json" --body "{\"temp\":25.4}"
cmd signalr-start --url "wss://api.example.com/chathub" --token "eyJhbGciOi..."
cmd signalr-invoke --method "sendToAll" --args "[\"Node01\",\"Online\"]"

7. File Explorer & Native FTP Server​

CommandArgumentsDescription
cmd fs-list-p / --path (String, Opt)Lists files and folders on Host MCU storage (default "/")
cmd fs-read-p / --path (String, Req)Streams a file from Host MCU storage
cmd fs-delete-p / --path (String, Req)Deletes a file or directory on Host MCU storage
cmd fs-mkdir-p / --path (String, Req)Creates a directory on Host MCU storage
cmd ftp-start-p / --port (Number, Opt)Starts the native RFC 959 FTP daemon (default port 21)
cmd ftp-stopNoneStops the active FTP daemon
cmd ftp-statusNoneQueries FTP daemon status ("RUNNING" or "STOPPED")

Examples​

cmd fs-list --path "/logs"
cmd ftp-start --port 21
